# Next

## Install and Setup
To install and setup a `Next.js` application:

```shell
# Create the Next application
$ npx create-next-app@latest my-app
# Change directory into the application folder
$ cd my-app
# Run the local development server
$ npm run dev
```

With a default setup, the following will be installed:

`Dependencies`:
- next
- react
- react-dom

`devDependencies`:
- @tailwindcss/postcss
- @types/node
- @types/react
- @types/react-dom
- eslint
- eslint-config-next
- tailwindcss
- typescript

To run the application locally:

```shell
$ npm run dev
```

The `Next.js` application will run on localhost:

- Local:         `http://localhost:3000`
- Network:       `http://192.168.1.24:3000`
