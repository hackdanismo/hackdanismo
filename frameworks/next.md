# Next

## Install and Setup
To install and setup a `Next.js` application:

```shell
# Create the Next application
$ npx create-next-app@latest my-app
# Change directory into the application folder
$ cd my-app
# Run the local development server
$ npm run dev
```

With a default setup, the following will be installed:

`Dependencies`:
- next
- react
- react-dom

`devDependencies`:
- @tailwindcss/postcss
- @types/node
- @types/react
- @types/react-dom
- eslint
- eslint-config-next
- tailwindcss
- typescript

To run the application locally:

```shell
$ npm run dev
```

The `Next.js` application will run on localhost:

- Local:         `http://localhost:3000`
- Network:       `http://192.168.1.24:3000`

## Tidy Up
Once the `Next.js` application is installed, the `app/` directory will look like this as the default:

```
app/
├── favicon.ico
├── globals.css
├── layout.tsx
└── page.tsx
```

Within the `app/page.tsx` file, remove all boilerplate code, leaving this:

```typescript
// app/page.tsx

export default function Home() {
  return (
    <div>
      <main>
        <h1>Home</h1>
      </main>
    </div>
  );
}
```

In the `app/layout.tsx` file, remove all boilerplate code, leaving this:

```typescript
// app/layout.tsx

import type { Metadata } from "next";

export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};

export default function RootLayout({ children }: LayoutProps<"/">) {
  return (
    <html lang="en">
      <body>
        {children}
      </body>
    </html>
  );
}
```

+ `page.tsx` defines the actual page for a route. This is the content of the page.
+ `layout.tsx` defines shared UI that wraps pages and nested routes. This is the layout/structure of the `page.tsx` page.
